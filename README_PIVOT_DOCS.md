## ?? Key Decisions Made

### 1. **Architecture: Plugin + SDK Hybrid** ?
```
80% users ? Built-in actions (http_request, jq_transform)
15% users ? Inline C# scripts (Roslyn compilation)
5% users  ? Plugin DLLs OR programmatic SDK
```

### 2. **Target Audience** ?
**Primary:**
- DevOps engineers (CI/CD orchestration)
- Integration architects (API workflows)
- Startup CTOs (automation on a budget)

**Secondary:**
- Data engineers (real-time ETL)
- Backend developers (BFF patterns)

### 3. **Business Model** ?
```
Open Source Core (MIT) ? Free, self-hosted
    ?
Managed Cloud (SaaS) ? $49-199/month
    ?
Enterprise ? Custom pricing
```

### 4. **Feature Priority** ?
**Phase 1 (Months 1-2):** Conditional branching, parallel execution, retry logic
**Phase 2 (Months 3-4):** Time-travel debugging, built-in actions, testing framework
**Phase 3 (Months 5-6):** Saga pattern, human-in-the-loop, visual designer

### 5. **Positioning** ?
> "KeryxFlux is to workflows what Docker is to containers:  
> Simple, declarative, developer-friendly, cloud-native."
